## Completed Features

### 5.1 Authentication
- [x] Google OAuth2 login (OmniAuth)
- [x] Automatic account creation on first login
- [x] Secure session management via Devise
- [x] Signup removed — login only via Google OAuth or existing credentials

### 5.2 Resume Upload & Parsing
- [x] Resume upload (PDF/DOCX) via Active Storage
- [x] Background parsing via Sidekiq (ResumeParsingJob)
- [x] Extracted data stored as JSONB (skills, experience, projects, certifications)
- [x] Resume change anytime from dashboard
- [x] Latest resume auto-used for report generation

### 5.3 Salary Benchmark Engine
- [x] salary_benchmarks table with role, city, experience_range, min/median/max salary, company_type
- [x] Seed data for 14 Indian cities (Bangalore, Mumbai, Delhi, Hyderabad, Pune, Chennai, Kolkata, Noida, Gurugram, Ahmedabad, Indore, Bhopal, Jaipur, Chandigarh)
- [x] Seed data for 9 roles (Software Developer, Frontend Developer, Backend Developer, Full Stack Developer, QA Engineer, Data Analyst, Data Scientist, DevOps Engineer, Product Manager)
- [x] 178 salary benchmark entries across all cities and roles
- [x] Underpaid percentage calculation: `((expected - actual) / expected) * 100`
- [x] SalaryBenchmarkService

### 5.4 Skill Gap Analyzer
- [x] skills table with name, category, demand_index, salary_uplift_index, learning_difficulty_index
- [x] role_skill_mappings table with role, skill_id, importance_weight
- [x] 60 skills across 15+ categories
- [x] 103 role-skill mappings
- [x] Skill ROI formula: `(salary_uplift_index * demand_index) / learning_difficulty_index`
- [x] Matched vs missing skills analysis
- [x] Skill ROI Analysis section on Career Blueprint page
- [x] SkillGapService

### 5.5 Interview Probability Score
- [x] Formula: `(skill_match% * 0.5) + (experience_score * 0.3) + (project_depth_score * 0.2)`
- [x] Score on 0-100 scale
- [x] Interview Readiness section with weak areas
- [x] InterviewScoreService

### 5.6 Career Roadmap Generator
- [x] 12-month structured roadmap (Foundation → Skill Building → Interview Sprint → Career Advancement)
- [x] Skill learning timeline
- [x] Recommended certifications
- [x] Salary projection (current, 6-month, 12-month)
- [x] AI Growth Hacks section
- [x] RoadmapService

### 5.7 Payment Integration (Razorpay)
- [x] Razorpay order creation API
- [x] Checkout with Razorpay JS SDK (Stimulus controller)
- [x] Payment signature verification (symbol keys fix applied)
- [x] Webhook validation (X-Razorpay-Signature)
- [x] Payment wall between free preview and full report
- [x] Payment model linked to career_report
- [x] One-time payment of Rs.999
- [x] After payment, all reports (old + new) are downloadable as PDF
- [x] PRO badge displayed for subscribed users (nav bar, dashboard, sidebar)

### 5.8 PDF Generation

- [x] Full career blueprint PDF (salary, skills, hacks, roadmap, certifications, projections)
- [x] Downloadable from Career Blueprint page and Dashboard

- [x] PdfGeneratorService
